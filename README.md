# iirose 点歌（网易云 + QQ 音乐）

在 iirose（蔷薇花园 / i站）网页里点歌的小脚本。单文件、纯前端、零账号、无混淆，可直接阅读审计。

## 使用（在 iirose 网页里注入即可，无需安装任何扩展）

1. 打开 <https://iirose.com>，登录并进入房间
2. 按 `Ctrl+S` 打开内置终端
3. 输入 `js -s` 回车（打开「自定义 JS」开关，输出 `Custom JS : 1` 即成功）
4. 输入 `js` 回车，弹窗粘贴下面的脚本地址，确定
5. 刷新页面，右下角出现可拖动的 🎵 悬浮球，点击即可搜歌点播

脚本地址（jsdelivr 国内可直连）：

```
https://cdn.jsdelivr.net/gh/Northseacaviar/iirose-dianbo/iirose-dianbo.js
```

## 点歌方式（同一个输入框，自动识别）

- **搜歌**：输入歌名或歌手（如「青花瓷」）回车 —— **网易云和 QQ 音乐会一起搜**，结果左边带来源徽标（红=网易云，绿=QQ）
- **链接点播**：粘贴链接或纯 id 回车
  - 网易云：`https://music.163.com/song?id=xxx` 或纯歌曲 id
  - QQ 音乐：`https://y.qq.com/n/ryqq/songDetail/<mid>`、手机分享的 `https://i.y.qq.com/v8/playsong.html?songmid=<mid>`、`https://y.qq.com/songDetail?mid=<mid>`，或纯 14 位 mid

## 两个源的能力差异（重要）

| | 网易云 | QQ 音乐 |
|---|---|---|
| 免费歌 | ✅ 可播 | ✅ 可播（能拿到完整直链的歌） |
| 会员歌 | 走第三方接口尽量解 | ❌ **只给 60 秒试听 → 不播**，自动改点网易云同名单曲 |

QQ 会员歌的完整版需要绿钻账号，纯前端拿不到（官方接口不给浏览器跨域、免费第三方也不接受传入使用者自己的账号）。所以点到会员歌时的行为是：

1. 自动去网易云搜同名单曲，能播就播，状态栏会提示「已自动改用网易云「歌名 - 歌手」」
2. 两边都没有可播版本时，状态栏给出明确原因 —— 不会出现「点了没反应」

注意回退到的「同名单曲」**可能是翻唱版**（例如周杰伦《晴天》网易云没有版权，会回退到翻唱），提示里会写清回退到了谁的版本。

## 说明

- **纯明文、零账号信息**：点播使用「你自己登录的 iirose 账号」，脚本不含任何他人账号/密码
- **音乐数据**：来自第三方公共 API（网易云：GD-Studio 直链/歌词 + NeteaseCloudMusicApi 详情；QQ 音乐：api.vkeys.cn），免费、无需登录
- **更新**：站点每次刷新会重新加载脚本地址，改版后刷新即更新

## 开发与测试

- `tests/m1_verify.js` —— 数据层验收（把脚本里 QQ 数据层的真实代码抽出来在 Node 里跑，53 项断言）
  ```
  node tests/m1_verify.js
  ```
- `tests/mock-iirose.html` —— 假 socket 的 iirose 房间，浏览器打开即可端到端驱动真实 UI（需起静态服：`python -m http.server 8790`）
- `docs/` —— 可行性报告、立项文档、独立审查报告

## 停用

终端输入 `js -s` 关闭开关，或刷新后弹窗点移除。
