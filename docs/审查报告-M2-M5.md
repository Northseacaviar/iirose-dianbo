## 严重

### S1 回退/失败提示把「整曲时长」当「试听时长」，且判不了完整性时误报成"试听"
- 代码：`508` `reason = '只给 ' + Math.round(song.duration || 0) + ' 秒试听片段';`
- 实测证据（真实浏览器驱动真源码）：
  - 会员歌《晴天》→ `QQ 音乐只给 269 秒试听片段，已自动改用网易云「晴天 - 周杰伦」`。269 = 整曲时长（vkeys `interval=4分29秒`），**试听实为 60 秒**（本仓库 README 自己写的就是 60 秒；可行性报告实测 `loadedmetadata duration=60.0s`）。
  - interval 缺失 / geturl 未给 size 时 → `失败：QQ 音乐「无时长歌」只给 0 秒试听片段，网易云也没有同名单曲`。此时插件根本没判定"是试听"，只是"判不了"，属误报。
- 修法：
```js
let reason;
try {
  const got = await qqGetUrl(song.mid, song.duration);
  if (got.complete) return sendQq(song, got);
  reason = /试听/.test(got.quality || '')
    ? '只给 60 秒试听片段（会员曲目）'                       // 60 = 实测值，别用 song.duration
    : '拿不到可确认的完整版（接口未给码率/时长，无法判定）';
} catch (e) { reason = e.message || '拿不到播放链接'; }
```

## 中等

### M1 事件 `d` 兜底后仍可能为 0，且 UI 照报「已点播」
- 代码：`557-558`（`duration` 最终可为 0）+ `564` `Math.round(duration)` 直接进事件。
- 实测：真源码发出 `&1{"s":"s://…","d":0,…,"b":"@2"}`，状态栏「已点播：无时长歌 - 测试」。触发条件：`interval` 解析不出（或链接路径详情缺 interval）且 geturl 未给 `size`。
- 网易云路径同形（`539-540`，实测可发出 `d:0.225`），顺手一起兜。
- 修法：
```js
let duration = song.duration;
if (!duration) duration = got.size && got.kbps ? (got.size * 8) / (got.kbps * 1000) : 0;
duration = Math.max(1, Math.round(duration || 0));   // d 必须为正
```

### M2 回退链全程无进度反馈，最坏 ~70 秒才有结果（用户视角＝点了没反应）
- 代码：`694-703` 点击后只改按钮；`dianbo` 期间状态栏保持搜索文案。
- 实测：点击后 1 秒状态栏仍是「找到 1 首（网易云 0 / QQ 1）…」，直到结束才变。
- 耗时上界（按 `85/96/254` 的 10s 超时累加）：geturl 10s + 回退搜索（GD 10s + NCM 2×10s）30s + 回退点播 30s（并发）≈ **70s**。
- 修法：`btn.onclick` 里先 `setStatus('获取直链中…','#999')`；`dianbo` 回退前 `setStatus('QQ 拿不到完整版，正在回退网易云…','#999')`（同作用域可直接调）。

### M3 封面取色无超时 → 理论上可永久停在「点播中…」
- 代码：`441-447` `new Image()`，只有 `onload/onerror`。
- 实测：把封面请求设为"挂起不回调"后 8 秒仍 `点播中… / disabled=true`、`__SENT__.length === 0`，无任何超时自愈。真实触发＝封面 CDN 连接挂住（不 load 也不 error）；QQ 封面域无 ACAO 会立即 error（已复核：`y.qq.com` 封面 HTTP 200 但无 `Access-Control-Allow-Origin` 头），故属罕见但不可自愈。
- 修法：
```js
await new Promise((resolve, reject) => {
  const t = setTimeout(() => reject(new Error('封面加载超时')), 3000);
  img.onload = () => { clearTimeout(t); resolve(); };
  img.onerror = () => { clearTimeout(t); reject(new Error('封面加载失败')); };
  img.src = coverUrl;
});
```

### M5 `qqExtractMid` 兜底过宽：裸 14 位串 / 非歌曲页 token 被当歌曲 mid
- 代码：`387-391`。
- 实测（真源码 Node 探针）：`abcdefghijklmn` → 原样当 mid（关键词搜索被跳过，必然失败）；`12345678901234` → 同；`y.qq.com/n/ryqq/singer/001BLpXF2DyJe2`、`.../albumDetail/002fRO0N4FftzY` → 都被当歌曲 mid（专辑/歌手 mid 也是 14 位，token 本身无法区分）。
- 修法：裸 token 要求字母+数字混合（QQ mid 实测均混合）：
```js
if (/^(?=.*[A-Za-z])(?=.*\d)[A-Za-z0-9]{14}$/.test(t)) return t;   // 391
```
并在 `doSearch` 里对"是 y.qq.com 链接但取不到 mid"的情况给明确文案（"这是专辑/歌手页，请粘贴单曲链接"）。

## 五个重点的结论

1. **回退链完整性 ✔**：三条出口齐全且都有文案——① 回退目标找不到 → `失败：QQ 音乐「X」…，网易云也没有同名单曲`；② 回退目标也播不了 → `…；改用网易云「…」也失败（原因）`；③ QQ 直链拿不到/业务错误 → 同一链路。无静默失败、无死等（唯一无界等待是 M3 的封面，且需异常网络）。但"点了没反应"的**观感**问题真实存在（M2/M3）；唯一错误信息是 S1。
2. **类型码/字段**：全文件只有两个 `send` 点（`546/547`、`563/564`），QQ 出口显式 `@2`、网易云显式 `@0`，**无漏传、无默认回退成 @0 的路径**（`type || NETEASE_TYPE` 默认值目前不会被触发，仅对未来加源是隐患 A3）。`d` **不保证为正** → M1。
3. **死代码**：无完全未用的函数；M6 列出的分类/字段是空转。
4. **UI 健壮性**：disabled/textContent 在成功、失败、回退三种路径后都正确恢复（实测）；同一行三连点只发出 1 组消息（`disabled` 同步置位奏效）。文案问题见 S1/M4。"回退到翻唱版"是**说清楚了的**：实测提示 `已自动改用网易云「晴天(深情版) - Lucky小爱」`。
5. **网易云零回归 ✔**：`1070627→HEAD` diff 仅新增 `type` 实参与返回值/文案；实测仍发 `m__4@0`、`mc=ec4141`、卡码率 320、事件 `b=@0`，时长/歌词/封面路径未动。`tests/m1_verify.js` 今日复跑 **53 PASS / 0 FAIL**（真实接口）。
   - 附带复核：直链 https 化后 `206 Partial Content, audio/mpeg`（总 10578809 字节）**可播**；`http://` 对照也 206，但在 https 页面会被混合内容拦掉 → 改写真有必要。会员歌判定线上仍正确（`quality=音乐试听` + `kbps=28` → 不完整），免费歌 `quality=HQ高音质` + `kbps=319` → 完整。
